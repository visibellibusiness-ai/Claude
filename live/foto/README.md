# Foto dei vincitori

Qui vanno le foto che fanno partire il post celebrativo di fine tabellone
(l'unico input manuale del tool). Nome file: lo slug dell'evento che il giro
stampa nel log quando il tabellone si chiude, ad esempio:

    Tabellone chiuso, in attesa della foto: live/foto/sat-mens-doubles-open.jpg

Formati accettati: .jpg, .jpeg, .png. Appena la foto è nel repo, al giro
successivo esce il carosello: cover con la foto, il cammino del tabellone,
slide finale "Congrats" ricondivisibile. La foto si può passare anche in chat
ad Andrea o a Claude, che la committa qui.
