## Come si aggiorna

Quando una conversazione produce o modifica un'offerta, il risultato va scritto
nel file corrispondente qui (e committato), così nessuna offerta vive solo in
una chat. Prima di inviare qualsiasi proposta a un cliente, passarla al vaglio
della skill `logica-offerte-commerciali`; per la formalizzazione usare la skill
`lettere-incarico`.
